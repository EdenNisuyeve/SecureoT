Partner logos

Place the four logo files in this folder with exactly these names:

  cisco.png
  siemens.png
  samsung.png
  huawei.png

Use the full-colour versions on a transparent background. The site shows them
in black and white and fades them to colour on hover. Until a file is present,
its cell shows a clean "logo" placeholder instead of a broken image.

All four share one canvas size (2611 x 1439) and are displayed at one shared
size. To change it, edit width / max-width on ".partner img" in css/styles.css.
